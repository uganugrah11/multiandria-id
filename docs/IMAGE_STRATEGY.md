## Image Selection Policy

The local working tree is the source of truth for uncommitted image assets.

Do not assume GitHub contains all imagery.

Every selected image must answer:
1. What does it show?
2. What does it prove?
3. Why does this page need it?
4. What crop works?
5. What text can safely sit near it?
6. Is the image authentic to Multi Andria?
7. Can the asset be optimized?
